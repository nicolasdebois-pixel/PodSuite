# Check-list de test (20 minutes, sur un poste de l'école)

À faire sur **un Mac et un PC Windows** de la salle, avec un compte étudiant, avant de distribuer une nouvelle version.
Notez ✓ / ✗ et ce qui s'affiche en cas de problème.

## Installation
1. ReaPack installé, adresse importée, paquet **Podcast & ADR Toolbox** installé sans erreur.
2. Action **Podcast & ADR Toolbox** : la fenêtre s'ouvre, le texte est **net** (pas flou) et lisible, la version s'affiche en bas à gauche.
3. Accueil › **Installer / réparer** : Whisper et le modèle s'installent, l'interface web est activée, le test final passe.
4. Le nom d'utilisateur contient-il un accent ou un espace ? Si oui, refaire le point 3 avec ce compte.

## Podcast
5. Dérushage : transcription d'un extrait de 2 minutes, page de dérushage ouverte, un passage barré → coupé dans REAPER.
6. Montage : ripple sur les bords activé ; tirer un bord droit puis un bord gauche : les voisins suivent en direct, sans fondu.
7. Fermer et rouvrir REAPER : le ripple sur les bords est toujours actif (case « Au démarrage de REAPER »).
8. Voix : Vocal level sur un item, puis « Annuler l'analyse » pendant l'analyse : rien n'est modifié.
9. Export : Contrôle du niveau › Mesurer, puis Corriger automatiquement : verdict « Prêt pour l'export ».

## Doublage
10. Répliques depuis une VO (Whisper), traduction en français : les répliques sont traduites.
11. Bande rythmo ouverte sur un second écran **et** sur une tablette (même Wi-Fi) : la vidéo s'affiche et suit la lecture.
12. Windows : au premier accès depuis la tablette, le pare-feu demande l'autorisation pour REAPER.
13. Enregistrer une réplique (arrêt automatique), puis en continu (Arrêter) : les prises arrivent sur « Prises - Personnage ».
14. Quitter la page Enregistrement, puis enregistrer normalement sur une autre piste : **l'enregistrement fonctionne** (mode normal rétabli).
